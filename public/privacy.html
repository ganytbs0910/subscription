プライバシーポリシー

gan（以下「開発者」）は、AI Subscan（以下「本アプリ」）における個人情報保護方針を定め、個人情報保護の仕組みを構築し、個人情報保護の重要性の認識と取組みを徹底することにより、個人情報の保護を推進致します。

取得する情報

本アプリは、サブスクリプション（定期課金）の管理を目的として、以下の情報を取得します。

1. Googleアカウント情報

ユーザーのGoogleアカウント（メールアドレス、表示名）をGoogleサインインにより取得します。

2. Gmailのメールデータ

Gmail API（読み取り専用）を使用し、サブスクリプションに関連する領収書・請求通知メールを検索・取得します。対象は以下の送信元からのメールに限定されます。

  • no_reply@email.apple.com（Apple）
  • googleplay-noreply@google.com（Google Play）
  • auto-confirm@amazon.co.jp（Amazon）
  • digital-no-reply@amazon.co.jp（Amazon Digital）

3. iCloudメールデータ（任意）

ユーザーが任意でiCloudメールのアプリ用パスワードを入力した場合、IMAP経由で領収書メールを取得します。

情報の利用目的

取得したメールデータから以下の情報のみを抽出し、サブスクリプション管理機能を提供するために利用します。

  • サービス名
  • 金額・通貨
  • 請求日
  • 請求サイクル（月額・年額等）

メールの本文・件名・添付ファイル等の全文は保存しません。解析処理はメモリ上で一時的に行われ、完了後に破棄されます。

お客さまからお預かりした個人情報は、開発者が契約するサーバに送信され、アプリ内でのランキング保存および表示に使用、及び使用予定です。

広告配信のためにGoogle Admobを使用、及び使用予定です。

サービスの品質向上のためGoogle社が提供するGoogle Analyticsを使用、及び使用予定です。

Google Admob、Google Analyticsにより取得される情報の項目、利用目的、およびプライバシーポリシーについては、以下URLよりご確認ください。

  • Google のポリシーと規約の広告
  • Google Analyticsの概要
  • Google社のプライバシー ポリシー

その他、利用者様からのご要望やご依頼内容などの確認、応対の品質向上およびサービス向上のために利用する場合が有ります。

データの保存場所

抽出されたサブスクリプション情報は、ユーザーの端末内にのみ暗号化して保存されます。開発者のサーバーにユーザーの個人データを保存することはありません。

iCloudメールの処理にはサーバーを経由しますが、メール内容およびアカウント情報はサーバー上に一切保存されず、処理完了後に即座に破棄されます。

個人情報の第三者への開示・提供の禁止

開発者は、お客さまよりお預かりした個人情報を適切に管理し、次のいずれかに該当する場合を除き、個人情報を第三者に開示いたしません。

  1. お客さまの同意がある場合
  2. 合併、会社分割、営業譲渡その他の事由によって個人情報の提供を含む弊社の事業の継承が行われる場合
  3. 法令に基づき開示することが必要である場合

個人情報の安全対策

開発者は、個人情報の正確性及び安全性確保のために、セキュリティに万全の対策を講じています。

Google API Services User Data Policy への準拠

本アプリにおけるGoogleユーザーデータの利用は、Google API Services User Data Policy（Limited Use要件を含む）に準拠します。

https://developers.google.com/terms/api-services-user-data-policy

データの削除

本アプリを端末から削除することで、保存されたすべてのデータが削除されます。また、Googleアカウントのアクセス権限は以下から取り消すことができます。

https://myaccount.google.com/permissions

アプリ本体からの利用者情報の送信停止と削除

本アプリは、利用者情報の送信を停止する手段を提供しておりません。送信を停止したい場合には、端末から本アプリを削除してください。

プライバシーポリシーの改定について

開発者はプライバシーポリシーの内容は予告なく変更する場合があります。改定されたプライバシーポリシーは、すみやかに開発者のウェブサイトに掲載いたします。

児童の安全保護ポリシー

1. 禁止事項

  • 児童に対する性的な内容の投稿
  • 不適切な画像・動画の共有
  • 個人情報の要求や共有
  • ハラスメント行為

2. 監視・報告の仕組み

  • 全てのコメントを監視しています
  • 不適切なコンテンツの通報機能を提供

3. 対応措置

  • 違反コンテンツは即座に削除
  • 違反ユーザーはアカウント停止
  • 重大な違反は関係当局に報告

4. 技術的対策

  • 不適切な言葉のフィルタリング機能
